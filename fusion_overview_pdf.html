Overview Document

FUSION is a next-generation cooperative gig-economy platform connecting customers with verified trade artisans — powered by a fair 90/10 revenue model, real-time GPS tracking, 100% escrow payment protection, and a peer-funded Mutual Welfare system that eliminates corporate middlemen entirely.

🎯 Problem Solved

Over 88% of India's gig-economy trade artisans face 25–40% commission deductions, zero social security, no healthcare, and no grievance mechanism from corporate aggregators like UrbanClap.

✅ FUSION Solution

A cooperative platform with 90% direct worker payout, mutual welfare fund (10%), live GPS tracking, escrow-protected payments, dispute resolution, and welfare claims — all backed by Supabase.

🏗️ System Architecture — 3-Tier Design

FUSION uses a strict 3-tier layered architecture. The React SPA talks to Supabase directly for auth and CRUD via the JS client, and to the Express backend for privileged operations requiring service_role access.

🔒 Row-Level Security (RLS) Policy Examples

Customers: Own Bookings Only

CREATE POLICY "customer_own_bookings"
ON bookings FOR SELECT
USING (auth.uid() = customer_id);

Workers: Assigned Jobs Only

CREATE POLICY "worker_assigned_jobs"
ON bookings FOR SELECT
USING (auth.uid() = worker_id);

Admin: Unrestricted Access (UID-verified)

CREATE POLICY "admin_all_access" ON bookings FOR ALL USING (EXISTS (SELECT 1 FROM profiles WHERE id=auth.uid() AND role='admin'));

Core Features, Security & Cooperative Model

🌟 Core Platform Features

📍 GPS Map Integration (Leaflet + Nominatim)

  • Customer: interactive address picker with draggable marker
  • Browser GPS auto-detects current location (permission-based)
  • Reverse geocoding via Nominatim — raw coords never shown
  • Address: House · Street · Area · City · State · PIN Code
  • Worker: read-only job site map for accepted bookings
  • Customer: 5-stage animated booking tracking map
  • Map tiles: Esri World Street Light (clean, Google Maps-like)

💸 Cooperative Escrow Payment Model

  • Customer pays 100% upfront — locked in Supabase escrow
  • Payment held until worker marks job as completed
  • 90% instantly released to worker upon job completion
  • 10% auto-transferred to Mutual Cooperative Welfare Fund
  • Zero hidden fees, zero surprise deductions
  • Full payment history in payments table

🛡️ Admin Control Panel

  • Real-time platform metrics (revenue, bookings, workers)
  • Worker verification & certification management
  • Service catalog management (create / edit / deactivate)
  • Dispute resolution: open → reviewing → resolved
  • Welfare claim approvals from cooperative fund
  • Financial overview: escrow, platform fees, worker payouts

🤝 Mutual Welfare & Skilling System

  • 10% of every booking funds the Cooperative Welfare Pool
  • Workers file claims: Medical / Equipment / Training
  • Peer-review committee approvals by admin
  • Emergency medical aid processed within 24 hours
  • Skill certification reimbursements available

Sub-ms HMR. Tree-shaking on production. Lazy-loaded route components per role.

📡 Supabase Realtime

WebSocket subscriptions for live booking updates — no polling required.

🗃️ DB Indexes

PostgreSQL indexes on customer_id, worker_id, status — O(log n) queries at scale.
